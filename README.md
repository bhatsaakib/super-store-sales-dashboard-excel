Super Store Sales Dashboard | Microsoft Excel

Project Overview

An interactive sales dashboard built using Microsoft Excel to analyze sales performance and key business metrics.

Dashboard Preview ![Super Store Dasboard](Dashboard%20Image.png)

Key Performance Indicators (KPIs)

* Total Sales
* Average Sales
* Total Transactions
* Total Quantity

Business Analysis

* Sales by shipping mode
* Regional sales analysis
* Top 5 cities by sales
* Transactions by product category
* Quantity ordered by customer type
* Monthly quantity trends

Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* KPI Reporting
* Data Visualization

Project Objective

To transform raw sales data into an interactive dashboard that helps users explore sales performance and identify business trends.

Project Files

* Dashboard.xlsx — Excel dashboard
* Superstore Data.xlsx — Source dataset
* KPI screenshots — Supporting visualizations
